What Git Really Is 🧅
TL;DR: Git is a content-addressed key-value store at its core. By the end, you'll understand why Git works the way it does.
Git is an onion
Think of Git as layers of an onion. Peel one back and there's something deeper underneath...
The Core: A Persistent Map
At its heart, Git is a database that maps any sequence of bytes to a SHA1 hash key.
echo "Apple Pie" | git hash-object --stdin
# adc0c94a3c2b17062fd455a5...
A few things worth knowing about this: the same content always produces the same hash — anywhere in the world.
